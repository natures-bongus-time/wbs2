# my design guide

## colors
- main:         #FF5A00   (headings, buttons)
- secondary:     #d10000   (accents, little details)
- light neutral: #f7d374   (background)
- dark neutral:  #2b1600   (text, borders)


## sizes
- heading:     5vh
- subheading:  3.25vh
- body:        2.5vh

## fonts
- headings: special elite (it has the typewriter feel that I want)
- body:     didactic gothic
## story
landing -> about the tool -> how to use -> the tool

## motion + sound
- sections fade up as they appear
- one soft click on the "keep going" button, with a mute toggle
